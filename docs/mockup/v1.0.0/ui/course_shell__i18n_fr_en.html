3 Le même écran dans les deux langues

Slide « tout est un Operator » du module 01. Ce qui change : textes, libellés du moteur (callout, boutons, aide). Ce qui ne change pas : commandes, noms d'objets Kubernetes/OpenShift, emojis, structure.

Blocs de code : les commandes restent identiques ; seuls les commentaires (# …) sont traduits. Le contrôle de parité de validate.js comparera les lignes de commande, pas les commentaires.

4 Mobile (≤ 900 px)

Le sélecteur reste dans la barre du haut (il tient en ≈ 70 px) ; le fil d'Ariane se tronque avant lui. Le compteur de slides disparaît sous 480 px pour laisser la place. Rappel de la langue en bas du menu latéral.

5 Comportement

Langue au premier chargement

  1. Paramètre d'URL ?lang=en (lien partagé), s'il est valide.
  2. Sinon la langue mémorisée (localStorage, clé du cours existante).
  3. Sinon la langue du navigateur (navigator.languages) si elle commence par fr ou en.
  4. Sinon fr

Stockage indisponible (navigation privée, file:// restrictif) : aucune erreur, la langue est simplement redemandée à la visite suivante.

Au clic sur l'autre langue

  1. Mémorise le choix ; met à jour <html lang>, le titre de l'onglet, l'URL (?lang=, sans recharger).
  2. Reconstruit la liste des slides dans la nouvelle langue : les adresses #mNN/i sont identiques (parité imposée).
  3. Réaffiche la même slide avec le même nombre de fragments révélés.
  4. Annonce « Langue : français » / « Language: English » (bulle 1,5 s, lue par les lecteurs d'écran).

Clavier et accessibilité

  • Raccourci l : bascule fr ↔ en (ajouté à l'aide en bas de page).
  • Ordre de tabulation : ☰ → sélecteur → 🌓.
  • Chaque bouton porte lang="fr" / lang="en" pour la prononciation.
  • Aucun rechargement : pas de perte de position ni de focus.

Ce qui reste commun aux deux langues

  • Progression (slides vues), scores des quiz, dernière slide, thème.
  • Adresses des slides : un lien #m07/5 pointe sur la même slide en fr et en en.
  • Site GitHub Pages et archive de release : une seule URL, un seul zip, les deux langues dedans.
